# Task

## Why this widget?

- Provides a unified interface for handling call and digital task workflows in the Contact Center.

## What is this widget?

- A modular React-based widget composing feature sub-components for different task scenarios.

## Use cases

- Accept/reject incoming tasks, control calls (mute/hold/transfer), outdial calls, manage CAD inputs, view/manage task list.
